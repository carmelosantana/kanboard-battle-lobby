# Changelog

## 1.2.0 — unreleased

- Declares a conflict with Harbor so ModMenu can enforce using one theme at a time.
- Renders Battle Lobby's appearance settings on the server for the first paint.
- Scopes Battle Lobby's page colours to pages it marks and preloads fonts only while the theme is active.

## 1.1.1 — unreleased

- No longer recommends TimeReport: nothing in Battle Lobby uses it yet, so ModMenu was prompting for a plugin that changes nothing.

## 1.1.0 — 2026-11-17

- Everything sits square: no skewed tabs, cards or loading bar, no slanted buttons, no spinning confetti, no italic display type.
- Fix: the storm due-date chip was painted over by the card's tier edge.
- Fix: on phones the fixed character lineup covered a third of the board; it now hides below 640px.
- Fix: the victory title wrapped onto two lines on phones; it now scales with the viewport.
- Fix: READY UP gave no feedback on a network error or an expired session; it now shows TRY AGAIN.

## 1.0.0 — 2026-10-07

- First release: battle-royale lobby theme with original characters, rarity-tier cards, storm due-date chips, READY UP, victory overlay, loading screen, login hero, admin defaults with per-user overrides.
